# 무선 다중 접속 방식 (Multiple Access)

> 최종 업데이트: 2026-06-14 | 1G~5G 다중 접속 기술 진화 기준

## 개념

**무선 다중 접속(Multiple Access)** 은 **수많은 단말이 한정된 무선 주파수를 어떻게 나눠 쓸지** 정하는 방법이다. 기지국 하나에 수백·수천 단말이 붙는데, 같은 주파수를 동시에 막 쓰면 서로 간섭하므로 **자원을 나누는 규칙**이 필요하다.

> 비유: 한 강당(주파수)에서 여러 사람이 동시에 대화해야 할 때, 섞이지 않게 **자리를 나누는 규칙**. 주파수로 나눌지, 시간으로 나눌지, 코드로 나눌지에 따라 방식이 갈린다.

이는 [무선-채널.md](무선-채널.md)의 "채널"과는 다른 층위다. **다중 접속은 "자원을 단말별로 나누는 방법"**, 채널은 "그 자원을 용도(음성/신호)별로 나눈 통로"다. 다중 접속 위에 채널이 얹힌다.

## 세대별 진화 — 무엇으로 나누나

| 방식 | 나누는 기준 | 세대 |
|------|-----------|------|
| **FDMA** | 주파수 | 1G |
| **TDMA** | 시간 | 2G (GSM) |
| **CDMA** | 코드 | 2G(한국)·3G |
| **OFDMA** | 잘게 쪼갠 주파수 × 시간 | 4G·5G |

### FDMA (Frequency Division) — 주파수로 나눔

사용자마다 **다른 주파수**를 하나씩 할당한다. 라디오 방송국이 주파수별로 갈리는 것과 같다. 가장 단순하지만, 사용자 수만큼 주파수가 필요해 **효율이 낮다**. 1G 아날로그가 사용했다.

### TDMA (Time Division) — 시간으로 나눔

하나의 주파수를 **시간 슬롯으로 쪼개** 사용자가 순번대로 돌려 쓴다. "지금은 네 차례, 다음은 내 차례"로 빠르게 번갈아 써서 동시에 쓰는 것처럼 보인다. **2G GSM**의 방식이며, [무선-채널.md](무선-채널.md)의 물리 채널(주파수+타임슬롯)이 바로 이것이다.

### CDMA (Code Division) — 코드로 나눔

모두가 **같은 주파수를 동시에** 쓰되, 사용자마다 **고유한 코드**를 부여해 구분한다. 시끄러운 파티장에서 여러 쌍이 각자 다른 언어로 대화하면 자기 언어만 알아듣는 것과 비슷하다. **한국 2G와 3G**가 이 방식을 썼다(퀄컴 주도).

### OFDMA (Orthogonal Frequency Division) — 4G·5G의 핵심

넓은 주파수 대역을 **수많은 좁은 부반송파(subcarrier)** 로 잘게 쪼갠다. 이 부반송파들이 **"직교(orthogonal)"** 라 촘촘히 붙여도 간섭 없이 분리된다. 그렇게 만든 **시간 × 주파수 2차원 격자(자원 블록)** 를 단말들에게 **필요한 만큼 칸을 배분**한다.

> 비유: TDMA가 "회의실 하나를 시간 순번으로 돌려쓰기"라면, OFDMA는 **큰 강당을 잘게 나눈 수백 개 좌석**을 만들어 각자에게 필요한 만큼 좌석을 배정하는 것이다. 동시에 여러 명이 각자 필요한 양만큼 효율적으로 쓴다.

장점이 LTE/5G의 고속 데이터망에 맞아 채택됐다.

| OFDMA 장점 | 설명 |
|-----------|------|
| 고속 | 부반송파 여러 개를 묶어 한 단말에 몰아주면 빠른 전송 |
| 고효율 | 직교 특성으로 주파수를 촘촘히 활용 |
| 간섭에 강함 | 신호가 벽에 반사돼 여러 경로로 들어와도(다중경로) 견딤 |

## 정리

- **다중 접속** = 여러 단말이 한정된 무선 자원을 나눠 쓰는 방법 ([무선 채널](무선-채널.md)과는 다른 층위)
- 계보: **FDMA(주파수) → TDMA(시간) → CDMA(코드) → OFDMA(잘게 쪼갠 주파수×시간)**
- **OFDMA** = 4G·5G의 핵심. 직교 부반송파를 격자로 배분해 고속·고효율 달성
